# Tense Shooter 3D

A fun 3D shooting game for kids to learn 8 English tenses.

## Features

- 6 cute 3D cartoon characters
- 8 English tenses with bilingual teaching lessons
- Voice reading (TTS) for lessons, examples and questions
- 3D shooting — tap or click correct answer bubbles
- Timer bonus — answer faster for more points
- 3 difficulty levels (Hard bubbles move)
- Regenerate questions anytime
- Pause / Quit during game
- Progress, high scores and stars saved in browser

## How to Run

Open `index.html` in Chrome, Edge or Firefox.

Or run: `npx serve .`

## Controls

- Shoot: click / tap bubble
- Hear question: Hear button or press H
- Pause: Pause button or Space
- New questions: New Questions button
- Toggle SFX: speaker icon (top-right)
- Toggle Voice: face icon (top-right)
